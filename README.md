# Auction House

![Auction House](https://github.com/user-attachments/assets/1d1a266b-779f-4716-b92d-576bd1f948a8)

An online auction platform where users can browse active listings, place bids, create their own listings, and manage their profile.

## Description

Auction House is a Semester Project 2 built at Noroff. It is a vanilla JavaScript frontend that consumes the Noroff Auction API. Users can register, log in, and participate in auctions by bidding on listings or creating their own.

Key features include:

- Browse all active auction listings in a public feed
- Search for listings by title
- View a single listing with full details and bid history
- Place a bid on any active listing
- Create, edit, and delete your own listings
- View and update your profile — avatar, banner image, and bio
- Register and log in with a `stud.noroff.no` email address

## Built With

- HTML
- SCSS / CSS
- Vanilla JavaScript
- [Bootstrap 5](https://getbootstrap.com/)

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone https://github.com/edrivvoll/semester-project-2.git
```

2. Navigate into the project folder:

```bash
cd semester-project-2
```

3. Install the dependencies:

```bash
npm install
```

### Running

This project does not use a build step. Open any of the HTML pages directly in your browser, or use a local development server such as [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code.

The live deployed version is available at [https://e-auctionhouse.netlify.app](https://e-auctionhouse.netlify.app/src/feed).
